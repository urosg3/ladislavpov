# LadislavPOV <img src="Xw8DxtK2_400x400.jpg" width="40">
LadislavPOV is a personal fork and preservation mirror of the original POV Kodi addon.

The goal of this repository is to:

* preserve working POV releases,
* provide a stable personal backup repository,
* maintain compatibility with Kodi,
* and keep the addon available even when upstream repositories disappear.

This repository is independently maintained by Ladislav Urošević.

## Repository URL

https://urosg3.github.io/ladislavpov/

## Installation

Kodi → File Manager → Add Source

Add:

https://urosg3.github.io/ladislavpov/

Then install:

repository.ladislavpov-1.0.0.zip
